# skills

One folder per skill, each holding a `SKILL.md`. `metadata.type` says what each one is:

- `guide`: one Stacksync resource, such as syncs, or one method, such as getting started.
- `playbook`: how several resources work together, whatever the apps.
- `usecase`: a playbook applied to two named apps, proven on a live workspace.

Start from a folder in `templates/` and follow [CONTRIBUTING.md](../CONTRIBUTING.md). The list
below is written by `node scripts/generate-catalog.mjs`; do not edit it by hand.
